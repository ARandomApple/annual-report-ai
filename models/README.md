# OCR recognition model

`ch_PP-OCRv5_rec_mobile_infer.onnx` is the 16.6 MB PP-OCRv5 recognition
model distributed by the RapidOCR project. Its pinned source and SHA-256 are
recorded in `setup_ocr.py`. The bundled copy allows OCR on a cloud host
without downloading a model when a visitor uploads a PDF.

Source: https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/v3.4.0/onnx/PP-OCRv5/rec/ch_PP-OCRv5_rec_mobile_infer.onnx

RapidOCR: https://github.com/RapidAI/RapidOCR (Apache-2.0)
